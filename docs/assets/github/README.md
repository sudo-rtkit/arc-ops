# GitHub presentation assets

These assets accompany the English and Czech project READMEs for version 0.13.1.

- `hero-dark.png` and `hero-light.png`: README banners selected by the reader's colour scheme.
- `social-preview.png`: 1280 × 640 image prepared for the repository's social preview setting. Adding this file to Git does not configure that setting.
- App captures and feature tiles: framed browser-build views. `@2x` variants provide larger detail views.

Ops / Bedňák artwork belongs to this project. The captures use a seeded browser demo profile; its level, XP and coin values were taken from existing test fixtures. They are not captures of the owner's live desktop or game. The import review uses a synthetic recognition result and demonstrates the review UI, not recognition accuracy. No game screenshots or Embark logos are included.

Native window appearance, game interaction and Windows foreground behaviour are not demonstrated by these browser captures. The source design package is kept locally in `docs/design/github/`; only the final PNGs are needed for the published READMEs.
